## O que mudou nesta versão

```
[[QA]]

```

Isso garante compatibilidade tanto com o **Obsidian** quanto com o **app web (vault.html)**.

## Estrutura

Os arquivos de índice ficam **dentro** das pastas, com o mesmo nome da pasta (padrão Folder Notes).

## Como usar

1. Extraia este ZIP
2. Abra a pasta `Obsidian-Roda-da-Vida-v4` como Vault no Obsidian
3. Comece pelo **Brain.md**
4. Recomendado: plugins **Dataview** + **Folder Notes**
